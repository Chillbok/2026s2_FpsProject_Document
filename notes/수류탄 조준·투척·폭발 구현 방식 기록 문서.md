# 수류탄 조준·투척·폭발 구현 방식 기록

## 구현 개요

수류탄은 `GrenadeThrower`(플레이어 입력·애니메이션·투척), `GrenadeTrajectory`(예측 궤적), `Grenade`(투사체 신관·폭발)로 나뉜다. 기본 입력은 G를 한 번 눌러 조준하고 다시 눌러 던지는 방식이다.

## 조준과 투척

- 조준 시작 시 수류탄을 오른손 뼈에 붙이고 물리·충돌을 끈다. 핀 메시를 숨기고 Animator의 `GrenadeThrow` 레이어에서 오른팔 위주 애니메이션을 재생한다.
- 퀵드로우 포즈를 사용해 소총을 왼손으로 옮기고 오른손을 비운다. 권총을 꺼낸 상태, 탄약이 없거나 무기 교체/재장전 등의 동작 중에는 투척 시작을 막는다.
- 조준 중 마우스 휠로 투척 속도를 기본 14m/s에서 6~24m/s 범위로 조절한다. 카메라 기준 발사 위치 오프셋과 위쪽 각도를 적용해 시작 위치·속도를 계산한다.
- `GrenadeTrajectory`는 같은 시작 위치·속도와 `Physics.gravity`를 사용해 포물선을 단계별 계산한다. 각 구간을 SphereCast해 벽·바닥에 닿으면 선을 끊는다.
- 애니메이션 정규화 시간 0.72에서 수류탄을 손에서 분리하고 Rigidbody 물리를 켠다. 예측선과 동일한 위치·속도를 Rigidbody에 적용한다. 수류탄 소유량을 하나 줄인다.
- 수류탄 입력 중 사격/무기 조작 일부를 막고, 종료·취소 시 잠금과 애니메이션 포즈를 복구한다.

## 폭발과 피해

- 신관은 핀을 뽑을 때가 아니라 수류탄이 손에서 떨어져 `Release`될 때부터 기본 3.5초 계산한다.
- 폭발 시 이펙트·사운드를 만들고 외곽 반경 안의 콜라이더를 모은다. `IDamageable` 대상은 한 번만 처리하고, 2m 안은 최대 피해, 2~8m는 선형 감소, 8m 바깥은 피해 0으로 계산한다.
- 설정에 따라 폭발 시야를 레이캐스트해 벽에 막힌 대상의 피해를 제외하고, Rigidbody에는 폭발력을 적용한다.

## 범위 및 제약

- 투척 프리팹에는 Rigidbody와 `Grenade`가 필요하다. 프리팹이 비어 있으면 코드 설명대로 애니메이션만 재생될 수 있다.
- 피해 적용은 `IDamageable` 구현체가 있어야 실제 체력 변화로 연결된다. 현재 프로젝트 코드에서 커스텀 피해 구현체는 확인되지 않았다.
- 수류탄의 튜닝 값은 스크립트 기본값과 씬/프리팹 인스펙터 값이 다를 수 있으므로 구체적인 현재 적용값은 해당 인스턴스를 확인해야 한다.
