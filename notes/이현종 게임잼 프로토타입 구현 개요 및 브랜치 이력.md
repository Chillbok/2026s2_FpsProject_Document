# 이현종 게임잼 프로토타입 구현 개요 및 브랜치 이력

## 확인 기준

`/Users/junho/Repositories/Game_Jam_dlguswhd` 저장소의 로컬 `main`, 원격 추적 `origin/main`, `origin/feature/asylum-level-ai`와 이 브랜치들이 가리키는 커밋 이력을 확인했다. 확인한 시점에 로컬 작업 트리는 깨끗했다. `origin/feature/asylum-level-ai`의 끝 커밋 `5cd6ecd`는 `main`의 조상이며, 두 브랜치가 별도로 갈라져 서로 다른 기능을 유지하는 형태는 아니다.

아래 내용은 저장소에 커밋된 C# 스크립트, 씬·프리팹·에디터 도구와 문서를 바탕으로 정리했다. Unity 에디터에서 실제 플레이하거나 빌드 테스트한 결과는 아니다. KINEMATION 및 캐릭터·병원 에셋 일부는 저장소 밖에서 별도로 가져와야 하므로 이 문서만으로 완전한 재현을 보장하지 않는다.

## 프로젝트 구성

- 프로젝트는 Unity `6000.3.27f1`과 URP를 사용한다 (`ProjectSettings/ProjectVersion.txt`).
- 빌드 씬 순서는 타이틀 `Assets/Scenes/Title.unity`, 야외 마을 `Assets/Scenes/Bridge_Village.unity`, 병원 `Assets/Scenes/Abandoned_Hospital.unity`, AI 테스트 `Assets/Scenes/Test_map.unity`다 (`ProjectSettings/EditorBuildSettings.asset:7-19`).
- 사용자가 수행하는 흐름은 타이틀의 작전 브리핑에서 시작해 마을을 통과하고 병원에서 열쇠카드와 장부를 얻은 뒤, 야외로 돌아와 차량으로 탈출하는 구성이다. 테스트 맵은 이 흐름과 별도로 적 AI를 시험하는 씬이다.
- 공통 런타임 로직은 `Assets/Scripts` 아래 전투, 적, 플레이어, UI, 월드 시스템으로 나뉜다. KINEMATION의 플레이어·무기 동작을 프로젝트 코드가 연결하거나 보완한다.

## 브랜치와 커밋별 발전

### 공통 초기 이력

- `533dbee` (`Add FPS prototype: gunplay, player movement, enemy AI and test map`): FPS 플레이어 이동과 총격, 적 AI, 테스트 씬을 처음 추가했다. 체력·피격 판정, 에디터의 적 설정·맵 생성 코드와 진행상황 문서도 이 시점에 마련됐다.
- `5074a19` (`Add Asylum level, enemy awareness AI, doors, mission flow and gear`): 병원 씬을 구성하고 적 인식 단계를 순찰·경계·전투로 확장했다. 소음 전달, 문 상호작용, 열쇠카드·아이템, 임무 HUD와 레이저 조준 장치 등 잠입 플레이 시스템을 추가했다.
- `5cd6ecd` (`Track game scene as Abandoned_Hospital, rename test map to Test_map`): 병원 씬을 `Abandoned_Hospital`로 이름 붙여 추적하고 테스트 씬을 `Test_map`으로 정리했다. 씬 빌드 설정과 에디터 도구의 참조도 이에 맞춰 갱신했다.

### `origin/feature/asylum-level-ai`

이 브랜치는 `5074a19`의 병원·AI 기능을 포함하고 `5cd6ecd`에서 씬 이름과 NavMesh를 정리한 상태다. 따라서 이 브랜치의 주된 프로토타입은 단일 병원 내부의 잠입·수집·탈출이다. 플레이어는 병원에서 열쇠카드를 찾아 잠긴 지하 시체안치소에 들어가 장부를 회수하고 정문으로 나가도록 설계됐다. 레벨 의도와 적 배치는 `레벨디자인.md`, 생성 코드는 `Assets/Scripts/Editor/AsylumEnemyPlacer.cs:53-128`, `:130-288`에 있다.

### `main` / `origin/main`

`main`의 최신 커밋 `02de740`은 기능 브랜치의 후손이다. 병원 시스템을 제거하지 않고 외부 접근 레벨과 캠페인 진행을 추가했다.

- 야외 `Bridge_Village` 씬, 터레인·환경 머티리얼·NavMesh와 차량 모델 관련 자산을 추가했다.
- `Title` 씬의 브리핑·설정·조작 설명을 만들고, 빌드 씬 목록을 타이틀부터 시작하도록 갱신했다.
- 플레이어가 마을과 병원 사이를 오갈 수 있도록 씬 출입구, 도착 스폰 지점, 아이템·처치 상태 보존과 씬 사전 로딩을 추가했다.
- 닫힌 문 너머를 보는 내시경 카메라와 총탄 관통, 탄흔·피격 흔적을 추가하고 적 프리팹과 병원 씬을 갱신했다.
- 마을 씬의 플레이어·임무·적·NavMesh 구성은 `Assets/Scripts/Editor/VillageLevelBuilder.cs:59-120`이 생성한다.

## 외부 에셋 및 재현 조건

저장소의 `README.md`는 KINEMATION Tactical Shooter Pack, Abandoned Asylum, Gang members 캐릭터 팩을 별도 경로로 가져오도록 안내한다. 그중 KINEMATION 원본 수정 사항도 저장소에 포함되지 않는다고 진행상황 문서가 명시한다. 반면 Flooded Grounds와 차량 모델은 저장소에 들어 있으며, 일부 대용량 자산은 Git LFS 대상이다. 그러므로 씬의 직렬화 데이터만으로 참조 자산 전체가 저장소 안에 있다고 간주하면 안 된다.
