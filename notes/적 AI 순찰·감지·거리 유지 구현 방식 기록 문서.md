# 적 AI 순찰·감지·거리 유지 구현 방식 기록

## 확인 기준

`KILL_OR_DEAD` 저장소의 `develop`(2026-10-21 통합 커밋 `29a30bc`)를 기준으로 기록했다. `feature/enemy_AI`의 커밋 `44a420f`에서 적 AI 프로토타입을 추가했고, 이후 개발 통합 브랜치에 포함됐다.

## 구현 개요

`EnemyAI` 하나가 `Patrol`(순찰), `Chase`(추적), `KeepDistance`(거리 유지·후퇴) 상태 전환과 이동을 담당한다. `NavMeshAgent`가 목적지 이동을 처리하고 별도 애니메이션 기반 공격 시스템은 이 코드에서 확인되지 않는다.

## 상태와 이동

- 순찰 지점 배열을 순서대로 방문한다. 남은 거리가 `patrolPointTolerance` 이하가 되면 다음 지점으로 넘어가며 마지막 뒤에는 처음부터 반복한다.
- 시야에 플레이어가 보이면 순찰에서 추적으로 전환하고, 플레이어 위치를 `SetDestination`에 전달한다.
- 플레이어가 `attackStopDistance` 안에 오면 `KeepDistance`로 전환한다. 이 이름과 달리 실제 공격은 실행하지 않는다.
- `retreatStartDistance`보다 가까워지면 후퇴하고 `retreatStopDistance`까지 거리를 벌린다. 후퇴 위치는 플레이어로부터 떨어지는 방향으로 계산하고 `NavMesh.SamplePosition`으로 유효 NavMesh 위치를 찾는다.
- 후퇴하지 않는 동안은 에이전트를 멈추고 플레이어를 바라본다. 추적 거리보다 `distanceTolerance` 이상 멀어지면 다시 추적한다.

## 플레이어 감지와 복귀

- `eyePoint`에서 플레이어까지 거리 및 방향을 검사한다. 거리 제한을 넘거나 `Vector3.Angle(eyePoint.forward, 방향)`이 `viewAngle`보다 크면 보이지 않는 것으로 판정한다. 따라서 값 60도는 전방 기준 좌우 각각 최대 60도 범위다.
- `obstacleLayer` 레이캐스트에 장애물이 먼저 걸리면 시야가 차단된다. `playerLayer` 필드는 선언되어 있으나 현재 감지 코드에서 사용되지 않고 `player` Transform을 직접 참조한다.
- 추적 또는 거리 유지 중 시야를 잃은 시간이 `losePlayerTime`에 도달하면 순찰 상태로 돌아간다. 다시 보이면 타이머를 초기화한다.
- 선택된 적의 시야 범위와 거리 경계를 Gizmos로 그려 디버깅한다.

## 범위 및 미완성 사항

- 코드가 확인하는 것은 순찰·시야 감지·추적·거리 유지·후퇴다. 발사, 공격 판정, 피해, 소음 감지·경계도 시스템은 구현 범위에 포함되어 있지 않다.
- `NavMeshAgent`, 순찰 지점, 눈 위치, 플레이어 참조와 장애물 레이어를 씬에서 연결해야 한다.
- 기능 추가 커밋 메시지는 단독 컴파일과 모의 API 상태 전환 검사는 기록하지만 실제 Play Mode 및 전체 프로젝트 컴파일은 미검증이라고 명시한다.
