# 탭·홀드 입력 판정 구현 방식 기록

## 구현 개요

`PlayerTapHoldInput`은 Unity Input System의 `Interact` 액션을 구독해 누름(Press), 탭(Tap), 홀드(Hold), 취소(Cancelled) 이벤트로 입력을 분류한다. 실제 상호작용 행위는 이 컴포넌트가 실행하지 않고 이벤트 구독자에게 맡긴다.

## 판정 흐름

- 입력 시작 시 누른 시각을 저장하고 `Press` 이벤트를 즉시 발생시킨 뒤 홀드 판정 코루틴을 시작한다.
- 기본 탭/홀드 경계는 0.3초다. 경계보다 짧게 누르고 놓으면 `Tap`이다.
- 경계를 넘긴 뒤, 해당 상호작용의 홀드 요구 시간까지 누르고 있으면 놓기 전에도 `Hold`가 발생한다. 기본 홀드 요구 시간은 1초다.
- 홀드 발동 전에 경계를 넘긴 상태로 놓으면 `Cancelled`다.
- `HoldRequiredTime`은 외부에서 덮어쓸 수 있고, `ResetHoldRequiredTime()`으로 인스펙터 기본값으로 돌아간다. 상호작용 포인트별 요구 시간에 사용할 수 있다.
- 입력이 비활성화되거나 액션이 꺼지면 진행 중 입력을 이벤트 없이 취소하고 내부 상태와 코루틴을 정리한다.

## 이벤트 소비

`InteractionDetector`가 이벤트를 받아 UI에 전달한다. 대상이 탭만 지원하는 경우 누른 순간 실행할 수 있으며, 눌렀다 놓는 탭 이벤트와 중복 호출되지 않도록 UI가 해당 누름에서 이미 실행했는지 기억한다.

## 범위 및 제약

- 입력 액션은 `PlayerInput`의 액션 맵에서 이름 `Interact`로 찾아 연결한다. 액션 이름이나 Input System 설정이 달라지면 동작하지 않을 수 있다.
- 이 컴포넌트는 판정기이며, 게임플레이 결과는 UnityEvent 또는 이벤트 구독 측에서 구성해야 한다.
