# 공격 관련 스탯

| 항목           | 설명                            |
| ------------ | ----------------------------- |
| 공격력          | 한 발당 피해                       |
| 약점 공격 배율     | 적의 약점을 맞혔을 때 공격력에 곱하여 적용하는 배율 |
| 사격 소음 레벨 | 총알이 발사될 때마다 발생하는 소음 레벨        |
| 발사 속도        | 초당 발사하는 탄환 수                  |
| 조준 확대 배율     | 조준할 때 화면을 확대하는 배율             |

# 명중률 관련 스탯

| 항목                 | 설명                                        |
| ------------------ | ----------------------------------------- |
| 유효 사거리             | 무기 피해가 감소하기 시작하는 거리. 이 거리 전까지는 기본 피해가 적용됨 |
| 투사체 삭제 사거리         | 이 거리보다 먼 대상은 총알을 맞아도 피해를 받지 않음            |
| 비조준 사격 탄퍼짐 각도      | 정지 상태에서 비조준 사격 시 총알이 퍼질 수 있는 원뿔의 각도       |
| 이동 중 비조준 사격 탄퍼짐 각도 | 이동 중 비조준 사격 시 총알이 퍼질 수 있는 원뿔의 각도          |
