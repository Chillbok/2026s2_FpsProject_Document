# 벽타기 구현 방식 기록

## 구현 개요

`PlayerWallClimb`은 H키 입력과 벽 표식 컴포넌트(`ClimbableWall`)를 확인해 벽을 오르고 넘어가는 동작을 실행한다. 이동 가능한 벽을 물리 질의로 측정하고, 세 애니메이션 클립은 자세 표현에 사용하며 실제 플레이어 위치는 계산된 경로와 보정값으로 움직인다.

## 벽 판별과 경로 계산

- 카메라가 향하는 수평 방향으로 가슴 높이 레이를 쏴 `ClimbableWall`이 붙은 콜라이더를 찾는다. 기본 탐지 거리는 1.1m이며 벽을 정면에서 55도 이내로 바라봐야 한다.
- 벽 윗면은 아래 방향 레이로 찾고, 높이는 기본 1~5m 범위에서 허용한다(벽 컴포넌트의 높이 재정의가 있으면 적용).
- 벽 윗면을 5cm 간격으로 훑어 두께를 측정한 뒤, 시작·매달림·벽 위·착지 지점을 계산한다. 착지 지점은 바닥 레이캐스트와 `CheckCapsule`로 바닥 및 플레이어 공간을 확인한다.
- 조건이 맞지 않거나 착지 공간이 막힌 경우 동작을 시작하지 않는다.

## 애니메이션과 위치 보정

- `Up`(반복 등반), `Over`(벽 넘기 구간), `Land`(착지)의 3단계로 Animator `Climb` 레이어를 제어한다. 두 번째 클립은 2.12~3.03초 구간만 재생한다.
- 애니메이터가 포즈를 갱신한 뒤 `LateUpdate`에서 root 뼈의 프레임 간 이동량을 추출해 플레이어 본체로 옮기고, root 뼈는 저장한 원위치로 복구한다.
- 클립 전환 중이나 반복 클립이 되감기는 순간의 큰 root 이동은 실제 이동으로 적용하지 않는다. 남은 목표 경로 오차는 단계의 남은 시간에 분배해 보정한다. 수평 위치는 손이 벽에서 떨어져 보이지 않도록 별도 감쇠로 따라붙인다.
- 착지 단계의 높이는 애니메이션 root 이동 대신 시간 기반 곡선으로 계산해 다양한 벽 높이에서 바닥에 도달하도록 한다.

## 동작 중 잠금

등반 중에는 `CharacterController`와 이동·상호작용·수류탄·문 발차기 입력을 잠그고, Kinemation 무기 IK 출력을 낮춰 애니메이션 팔이 총 자세로 끌려가지 않게 한다. 설정에 따라 총 렌더러도 숨긴다. 정상 종료와 중단 모두 입력·무기 표시·IK를 복구한다.

## 범위 및 제약

- 지정된 `ClimbableWall` 표식이 없는 벽은 탈 수 없다.
- 벤더 내부의 protected 출력값을 건드리지 않기 위해 리플렉션으로 `TacticalProceduralAnimation`의 `_tacOutput`을 읽는다. 해당 벤더 구현 변경에 민감하다.
- `진행상황.md`에는 벽타기가 씬 인스턴스에만 붙고 `PlayerCharacter.prefab`에는 아직 반영되지 않았다고 기록되어 있다. 프리팹 반영 상태는 별도 확인이 필요하다.
