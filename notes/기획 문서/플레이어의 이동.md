# 이동이란?(서기 상태에서 이동하기)

플레이어는 `W`, `A`, `S`, `D` 키를 눌러 [[플레이어 캐릭터]]를 이동할 수 있다.

서기 상태에서 하는 이동과 앉기 상태에서 하는 이동으로 나뉘어지며, 이 두 가지 행동의 각종 요소들이 다르다.

## 각 이동의 차이

|           | 서기 상태에서 이동                                | 앉기 상태에서 이동                                    |
| --------- | ------------------------------------------------- | ----------------------------------------------------- |
| 이동 속도 | 기본 이동 속도가 적용됨.^[[#이동 속도]] 참조. | 애기 이동 속도 배율이 적용됨.^[[#이동 속도]] 참조. |
| 소음 레벨 | 2레벨 적용^[[[소음 시스템 동작 명세]] 참조]                | 1레벨 적용^[[[소음 시스템 동작 명세]] 파트 참조.]                |

## 이동 속도

| 항목                     | 값       | 비고                                                   |
| ---------------------- | ------- | ---------------------------------------------------- |
| 기본 이동 속도              | 3.0 m/s | 임시값(튜닝 대상)                                           |
| 전력 질주 속도 배율           | 1.8배    | 임시값(튜닝 대상). 기본 이동 속도에 비해 확실히 속도가 빨라진 것이 느껴져야 한다. |
| 앉기 이동 속도 배율           | 0.5배    | 임시값(튜닝 대상)                                           |
| 정조준 중 이동 속도 배율        | 0.5배    | 임시값(튜닝 대상)                                           |

각 속도를 따로 구현하지 않고 기본 이동 속도에 곱해지는 방식으로 구현한다. 이렇게 하는 이유는, **특정 기준을 잡고 관리하는 것이 편하기 때문**이다.
