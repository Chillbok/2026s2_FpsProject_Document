# 무기 모딩 테이블 구현 방식 기록

## 구현 개요

`WeaponCustomizationTable`은 `IInteractable`로 동작하는 런타임 무기 커스터마이징 화면이다. 실제 플레이어 무기와 별도의 프리뷰 무기를 보여주되, 부착물 변경은 프리뷰와 실제 무기에 함께 적용한다.

## 화면 진입과 프리뷰

- 활성 무기의 이름과 설정된 프리뷰 프리팹을 대조해 대응하는 프리뷰를 만든다. 실제 무기에 장착된 부착 상태를 프리뷰에 복제한다.
- 무기 종류와 소켓에 맞는 부착물만 슬롯별 선택 목록에 포함한다. 사용할 수 있는 항목이 없는 슬롯은 UI에 표시하지 않는다.
- Kinemation 카메라 애니메이터가 1인칭 카메라 Transform을 매 프레임 갱신하므로, 기존 카메라를 이동시키지 않는다. 별도 `ModdingCamera`를 켜고 1인칭 카메라를 끈다.
- 렌더러 바운즈와 화면 비율/FOV를 이용해 총이 화면에 들어오는 최소 거리를 계산하고, 근거리 클리핑 및 최대 거리 제한을 적용한다. 마우스 휠 줌과 Y키 좌우 반전도 지원한다.
- 진입 시 플레이어 렌더러와 입력을 숨기거나 잠그고 커서를 표시한다. 종료 연출 후 프리뷰를 제거하고 카메라·입력·커서를 복구한다.

## 부착물 조작과 UI

- 숫자키 1~5로 슬롯을 선택하고 A/D 또는 좌우 화살표로 해당 슬롯의 부착물을 순환한다. 빈 상태도 선택지로 포함한다.
- 변경 시 프리뷰와 실제 무기의 `WeaponAttachmentController`에 같은 장착/제거 처리를 호출한다.
- UI는 슬롯 소켓의 화면 투영 위치 옆에 박스를 배치해 장착 상태를 표시한다. 선택 슬롯을 강조하고, 총 반전 시 박스의 좌우 오프셋도 반전한다.
- 작업대 진입에 쓴 T키가 같은 프레임 종료 입력으로 재사용되지 않도록 입력 소비 프레임을 기록한다.

## 범위 및 제약

- 사용 가능한 무기 프리팹과 부착물은 작업대 인스펙터 배열에 등록되어 있어야 한다.
- 실제 무기와 프리뷰는 별도 인스턴스지만, 모딩 변경은 두 쪽 모두 즉시 적용된다. 저장 슬롯/인벤토리 기반의 별도 장비 저장 구조는 이 코드에서 확인되지 않는다.
- UI는 런타임에 생성되며 Unity UI의 Text/Canvas 구성과 모딩 카메라를 사용한다.
