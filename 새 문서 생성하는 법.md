`Ctrl` + `O`를 눌러 새 문서를 생성할 수 있다.

문서를 처음 생성하면 아무것도 없을 것이다.

미리 설정되어 있는 단축키 `Alt` + `T`를 누르면 템플릿 창을 열 수 있다.

![[Pasted image 20260928150650.png]]

여기에서 [[기본 문서 템플릿]]을 클릭한다. 그럼 아래와 같이 기본 템플릿이 적용될 것이다.

![[Pasted image 20260928150733.png]]

	

| 항목         | 설명                                                                                                                                                                                                                                                        |
| ---------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `aliases`  | 이 파일을 부르고 싶은 다른 이름을 작성하면 됨.                                                                                                                                                                                                                               |
| `작성 날짜`    | 기본으로 알아서 세팅되는 영역. 건드리지 말 것.                                                                                                                                                                                                                               |
| `작성자`      | `[[이준호]]` 이런식으로 작성자 본인의 이름을 적고, 엔터 누르면 됨.                                                                                                                                                                                                                 |
| `category` | 이 문서가 어떤 문서인지 보여주는 항목. 이 부분은 귀찮거나 잘 모르겠다면, 굳이 작성하지 않아도 됨. 관리자인 [[이준호]]가 문서 편집해 추가 가능함. 직접 해보고 싶은 경우에만 따로 [[이준호]]에게 컨택 바람.<br>여기에 있는 링크를 눌러보면, 동일한 카테고리의 어떤 문서가 있는지 확인할 수 있음. 조금 더 쉽게 문서들을 분류하기 위함임. 따라서, 문서들을 따로 폴더로 분류할 필요가 없음.<br><br>예시: ![[문서 생성 안내]] |
| `tags`     | 문서 유형을 작성한 항목. 마찬가지로 무언가 이미 작성되어                                                                                                                                                                                                                          |
보라색으로 강조된 글씨들은 모두 링크임. 누르면 다른 문서로 넘어갈 수 있음.
